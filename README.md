# 字感 · Type Feel

**简体中文** | [English](README.en.md)

专注文字与手感的打字练习。支持英文、中文和粤语，使用自己的输入法，练习记录仅存本机。

[开始练习](https://typefeel.app)

## 开始练习

选择语言和练习方式，点击正文或用 `Tab` 聚焦后输入。

- **三种语言**：英文、简体中文、繁体粤语口语文本。
- **六种方式**：15／30／60 秒，或短篇／中篇／长篇。
- **沉浸式输入**：当前输入行保持在固定位置，上下文逐渐淡出。
- **注音**：全拼、粤拼，或小鹤／自然码／微软／搜狗双拼提示。
- **手感设置**：光标形状、蓝色光晕、闪烁，以及四套机械键盘音效。
- **本地记录**：实时速度与准确率、最佳成绩和最近 100 次练习。

按 `Esc` 重练当前文本，点击「换一段」选择新文本。网页保留浏览器原有的 Cmd/Ctrl 快捷键。中文或粤语组字时，Esc 由输入法处理。

在「设置」中调整光标、注音、音效、界面语言和明暗外观。首次界面语言跟随浏览器：中文使用中文，其余使用英文；外观跟随系统。选择会保存在当前浏览器中。

## 网页游戏试玩

本分支增加「练习 / 游戏」切换。本地打开 `http://127.0.0.1:4173/#game` 即可试玩。

中文单字和词语从上方落下。使用自己的输入法，完整上屏后自动发射带光晕的光标，消除目标；也可以分次上屏组成词语。漏掉一个目标扣一条生命，五条生命耗尽后结算。每存活 30 秒提高一级。

点击「暂停」可暂停或切换模式。失去输入焦点或切到后台时自动暂停，点击「继续」恢复。非组字时按 `Esc` 重开，组字时保留输入法原有行为。游戏最高分和最近 20 局结果只存本机，与练习记录分开。首版词库包含 120 个中文单字和双字词。

游戏在 `codex/falling-words-game` 分支等待试玩评审，尚未合入 `main` 或发布到正式网站。验证范围见 [试玩验证记录](docs/verification/2026-11-09-falling-words.md)。

## 语料与隐私

内置 **288 篇原创短文**，三种语言各 96 篇，短／中／长各 32 篇。语料、注音词库和键盘音效随网站提供，练习不调用模型，也不上传输入内容。设置与统计保存在本机浏览器，清除网站数据后会一并清除。

网页使用内置语料；DSH 插件还可以读取当前 DSH 的近期本地对话。网页与插件的记录分别保存在各自环境，不会自动互通。首次访问需要联网；当前版本不提供离线安装。

## DSH 插件

网页与 [dsh-typing-practice](https://github.com/yishan/dsh-typing-practice) 共用练习源码。插件继续使用原有仓库和 npm 包安装，保留 DSH 本地对话语料及平台快捷键。

## 本地运行

需要 Node.js 22.12 或更新版本。

```bash
npm ci
npm run dev
```

打开 `http://127.0.0.1:4173`。修改代码后重新运行开发命令，或执行 `npm run build` 后刷新页面。

构建与同步方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。

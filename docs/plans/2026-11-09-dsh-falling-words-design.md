# DSH 落字游戏接入

用户已确认在新分支 `codex/dsh-falling-words-game` 实现；完成 DSH 验证后再评审合入主线。插件发布另行处理。

## 实现范围

- 在现有 `typing-practice` 主面板内提供顶部居中的「练习 / 游戏」切换，保留侧栏入口、模块名和全部已有练习存储键。
- 复用 `packages/practice/src/game` 的规则、输入、动画和声音。游戏初始难度、完整上屏匹配、清空输入、生命警示、计分和等级与网页版一致。
- 将品牌资源、存储键、容器布局和快捷键服务作为平台选项传入共享游戏页面。网页保留原有默认值和历史记录。
- DSH 游戏成绩使用 `dsh.typing-practice.game.records.v1`，游戏音效使用 `dsh.typing-practice.game.audio.v1`；键盘音效复用已有 `dsh.typing-practice.sound.v1`。
- 内容区域测量 DSH 面板容器，监听容器尺寸变化。切换面板、失焦、隐藏时停止声音和暂停；卸载时清理动画、观察器和快捷键占用。
- Esc 与 Ctrl/Cmd+P 暂停；DSH 原生快捷键占用仅在游戏页面挂载时有效。输入法候选操作不触发游戏快捷键。
- 语言、亮暗主题跟随 DSH。设置中提供玩法和两组音效控制，不添加网页专用的语言和外观选项。
- 游戏使用随包词库，客户端运行，不新增 Host 接口，不读取本地对话作为游戏词库。

## 实施与验证

1. 先增加失败用例，覆盖 DSH 存储隔离、音效偏好兼容、游戏打包和快捷键生命周期。
2. 实现共享页面的平台参数及模式切换，接入插件入口和构建。
3. 执行 `npm run build`、`npm test`，验证原练习和网页功能。
4. 使用独立验收环境加载真实 DSH 宿主及构建产物，验证模式切换、输入、暂停、面板尺寸、亮暗主题、中英文和四套声音。
5. 记录实际证据与原生系统输入法的验证边界，提交功能分支供评审。不更新 npm 或插件分发仓库。

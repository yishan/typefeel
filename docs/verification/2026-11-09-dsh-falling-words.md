# DSH 落字游戏验证

日期：2026-11-09

分支：`codex/dsh-falling-words-game`

## 环境与范围

- 宿主：本机已安装的 DeepSeek Harness 0.2.2-rc.1 官方运行时，通过其 CLI 启动独立 Web profile。
- 隔离目录：`/tmp/typefeel-dsh-game-home`，本机端口 4196。插件从本仓库 `dist/dsh-plugin` 本地链接安装。
- 浏览器：系统 Chrome，独立临时上下文。使用浏览器原生 AudioContext 解码和播放；组字确认使用 CDP IME 事件。
- 没有修改用户现用 DSH profile，没有调用模型或配置账号，没有更新 npm 或插件分发仓库。

## 实现

- 原侧栏 `typing-practice` 入口和 `dsh-typing-practice` 模块标识不变，在面板顶部中间切换练习与游戏。
- 游戏引擎、词库、输入确认、动画、音效和设置页面继续来自 `packages/practice/src`。共享模式切换由两个适配器调用。
- 游戏接收平台品牌、布局、快捷键和存储选项。DSH 测量内容面板并监听 ResizeObserver，网页保留窗口布局与原有存储默认值。
- 游戏成绩键为 `dsh.typing-practice.game.records.v1`，游戏音效键为 `dsh.typing-practice.game.audio.v1`；键盘偏好复用 `dsh.typing-practice.sound.v1`。已有练习键未更改。
- 插件声明等待 `slots` 与 `locale` 服务。实测修复了英文宿主启动时插件提前使用中文默认值的问题。
- DSH 主按钮前景映射到 `--dsw-alias-label-primary-foreground`。暗色主题下按钮文字对比度由约 1.05:1 提高到 18.08:1；浅色约 18.90:1。

## 验证边界与产物

本次验证使用真实 DSH Web 宿主，并非手写宿主模拟页。音频由浏览器原生接口处理。原生操作系统输入法候选窗的位置、真实手机软键盘，以及 DSH 桌面原生菜单向 DOM 的按键转发仍需在对应设备中人工验收；CDP 组字和固定快捷键服务检查不替代这些检查。

浏览器验收脚本及截图保存在 `/tmp/typefeel-dsh-acceptance.cjs`、`/tmp/typefeel-dsh-browser-smoke.cjs`、`/tmp/typefeel-dsh-contrast.cjs` 和 `/tmp/typefeel-dsh-game-*.png`。本地导出包的 `SOURCE.json` 记录准确源码提交。现有安装渠道需经过单独插件发布后才会获得本次功能。

## 光标颜色调整

按用户要求，游戏取消对练习光标颜色的覆盖。发射器、子弹、输入插入光标和光晕共用练习的 `--tp-cursor-color`。

在真实 DSH Web 宿主中比较实际计算颜色：浅色主题下四者与练习光标均为 `rgb(65, 118, 230)`，暗色主题下均为 `rgb(86, 134, 254)`。实际组字确认后检查了发射子弹的颜色，且输入仍正常清空。两种主题下的 390、320px 窄屏检查通过，无浏览器运行时错误。重新构建与 256 项测试均通过。

验证脚本：`/tmp/typefeel-blue-cursor-check.cjs`；截图：`/tmp/typefeel-dsh-game-blue-light.png`、`/tmp/typefeel-dsh-game-blue-dark.png`。
